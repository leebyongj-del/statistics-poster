# 우리 반 통계연구소

중학교 1학년 통계포스터 만들기 수업을 위한 웹앱입니다.

## 주요 기능

- 질문 정하기 → 자료 모으기 → 표와 그래프 → 해석하기 → 포스터 디자인
- 이름을 붙인 여러 자료 입력과 자료별 통계도구 선택
- 표와 그래프의 값 확인(마우스 또는 터치)
- 12가지 포스터 스타일, 18가지 색상 테마와 혼합 색상·그라데이션
- 브라우저 자동 저장, 작업 파일 내보내기와 불러오기, 인쇄

## 실행

별도 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 앱입니다. 저장소의 `index.html`을 브라우저에서 열거나, 저장소 폴더에서 다음 명령으로 로컬 서버를 실행하세요.

```sh
python -m http.server 8000
```

그런 다음 http://localhost:8000 에 접속합니다.

## 배포

정적 웹 호스팅에 저장소 루트의 파일을 그대로 올리면 됩니다. Vercel에서는 Framework Preset을 Other로 선택하고 빌드 명령 없이 루트 디렉터리를 배포할 수 있습니다.

## 저장 방식

작업은 현재 기기의 브라우저에 저장됩니다. 다른 기기로 옮기거나 보관하려면 ‘작업 파일 저장’을 이용하세요. 학생 자료를 서버로 전송하는 기능은 없습니다.
