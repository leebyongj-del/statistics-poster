# 우리 반 통계연구소

중1 통계포스터 수업 앱입니다. 역할 선택 → 교사 수업 개설 → 학생 수업코드 입장 → A3 포스터 작성으로 진행합니다.

## 수업 운영
- 교사 입장번호는 서버 환경 변수 `TEACHER_PIN`으로 설정합니다. 브라우저 소스에 포함하지 않습니다.
- 1학년 1반은 101, 1학년 2반은 102, 2학년 3반은 203입니다.
- 같은 반의 진행 중인 수업은 하나만 개설할 수 있습니다. 종료 후 다시 개설하면 별도 회차가 됩니다.
- 종료 즉시 서버의 작업 저장을 차단하고 학생 화면은 약 3초 안에 읽기 전용으로 바뀝니다. 연결 끊김 시에도 편집을 잠급니다.
- 학생 작업은 기기와 서버에 저장됩니다. 다른 기기로 옮길 때 작업 JSON을 내보내고 불러올 수 있습니다.
- 입장번호를 아는 사람은 교사 기능을 사용할 수 있으므로 학생에게 공유하지 않습니다.

## 평가 지원
주제 선정 이유, 자료별 출처·도수 단위, 분석·해석, 결론·실천 방안·느낀 점, 20점 채점요소 점검표를 지원합니다. 점검표는 입력 여부만 확인하며 자동 채점하지 않습니다.
12가지 디자인과 18가지 색상, 다중 자료, 표·그래프, A3 자동 맞춤을 제공합니다.

## 실행과 배포
Node.js 24 이상에서 `npm run dev`로 실행합니다. 로컬 테스트용 SQLite DB는 `.local/`에 저장됩니다. `npm test`로 수업 접근·종료 차단을 검사합니다.

프로덕션은 Cloudflare Worker와 D1이 필요합니다. `npm run build`는 public 파일을 Worker에 포함하여 `dist/server/index.js`를 생성합니다. Sites는 `.openai/hosting.json`의 DB 바인딩과 drizzle 마이그레이션을 배포합니다. `TEACHER_PIN`은 호스팅 서버의 비밀 환경 변수로 등록하세요.

이 버전은 서버 기능이 있으므로 GitHub Pages 또는 Vercel 정적 배포만으로는 수업 기능이 동작하지 않습니다. 다른 플랫폼에서는 D1에 해당하는 데이터베이스와 API 실행 환경을 별도로 연결해야 합니다.

## 제출 및 수업 현황
- 학생 상단의 교사에게 제출하기는 현재 포스터를 서버에 별도 스냅샷으로 저장합니다. 파일 다운로드가 필요하지 않습니다. 이후 편집은 제출본을 바꾸지 않으며 재제출로 갱신합니다. 수업 종료 후 제출과 수정 모두 서버에서 차단됩니다.
- 교사 수업 카드의 학생 현황에서 접속(45초 기준), 마지막 저장, 작업 단계, 자료·통계도구 개수, 제출 시각을 확인하고 작업/제출본을 읽기 전용으로 열 수 있습니다. 현황은 5초마다 갱신합니다.
- 학생에게 입장 전에 기록을 안내합니다. Page Visibility 및 pagehide 이벤트를 서버 수신 시각으로 기록하며, 복귀 확인된 시간만 합산합니다. 종료·통신 끊김·브라우저 제한 때문에 누락되거나 복귀가 미확인일 수 있습니다. 최근 2,000건을 현황에 표시합니다. 다른 탭의 내용·URL·화면은 수집하지 않습니다. AI 사용 판정/차단 기능이 아닙니다. 패들렛에 링크를 공유해도 기록 범위는 이 앱입니다.
- 쿠키 전달이 제한되는 배포 환경에서도 입장이 유지되도록 서버 발급 불투명 세션 토큰을 역할별 헤더로 전송합니다. 교사 토큰은 탭 세션 저장소, 학생 토큰은 이 기기의 작업 복귀용 저장소에 보관합니다. 서버에는 해시만 저장하며 만료와 역할을 검증합니다.

## 포스터 글꼴
포스터 디자인에서 제목·본문 글꼴을 각각 선택합니다. 기본 글꼴 포함 30종이며 선택한 웹 글꼴만 Google Fonts에서 불러옵니다(포스터 내용은 외부 글꼴 URL에 포함하지 않음). 글꼴 선택은 작업 파일·서버 저장·제출본에 보존됩니다. 로딩 후 A3를 다시 맞추고 앱의 인쇄 버튼은 글꼴 로딩 완료를 확인합니다. 학교망에서 Google Fonts가 차단되면 기본 글꼴을 선택하세요. 줄기와 잎 그림은 숫자 정렬용 고정폭을 유지합니다.
